## Project Overview

**ClassBoard** — Teacher dashboard app for tracking per-student reminders and per-class notes, integrated with the BelTools dashboard.

Two content types:
1. **Student reminders** — tied to a specific student, have due dates/status, can be resolved
2. **Class notes** — general info about a class (eval dates, curriculum progress, ongoing projects)

Context-aware: displays relevant info based on the current class in session (via BelTools integration).
